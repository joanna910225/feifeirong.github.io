## What I work on

- Reliability governance for long-running, failure-prone video operations that create real-world costs: cross-execution checkpoints, task reuse, and fail-closed behavior when a result is uncertain.
- A consistent HTTP node reliability layer with tiered timeouts, body-idle watchdogs, and structured contextual logs.
- A unified local / remote FFmpeg runner, with media compute delegated to function execution and object storage.
- Self-contained dependency governance and acceptance gates, including pinned vendored registries, AST-level network checks, and validate/check tooling.
