## Current direction

- Build structured `agents.json` and `plans.json` registries rather than another prose-only ranking.
- Compare auth methods, model and plan compatibility, licensing, maintenance activity, China availability, payment options, and real usage cost.
- Use GitHub data to flag release, activity, and license changes; keep benchmark results as referenced evidence rather than inventing a new leaderboard.

The project is still in progress. The first milestone is a small Chinese comparison site and an agent-plan compatibility matrix.
